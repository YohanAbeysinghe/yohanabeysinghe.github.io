# Publication figures

The Publications page uses figures from the corresponding papers and project pages. The downloaded PNGs retain the complete figure; large images are reduced to a maximum dimension of 1,000 pixels for the publication thumbnails. Clicking a thumbnail opens the local figure.

| Paper   | Local asset                       | Original source                                                                                                                                                                     |
| ------- | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VEGA    | `images/publications/vega.png`    | [Real-world navigation comparison](https://yohanabeysinghe.github.io/vega_website/static/images/vega/vega_comps.png) from the project page                                          |
| SynCast | `images/publications/syncast.png` | [Figure 2](https://media.springernature.com/lw685/springer-static/image/art%3A10.1038%2Fs44407-026-00076-3/MediaObjects/44407_2026_76_Fig2_HTML.png) from the npj Clean Air article |
| MAGNET  | `images/publications/magnet.png`  | [System overview](https://schowdhury671.github.io/magnet_project/static/images/Main_System.png) from the project page                                                               |
| VFace   | `images/publications/vface.png`   | [Figure 2: method overview](https://arxiv.org/html/2602.07835v2/overview.png) from the arXiv paper                                                                                  |

All four papers include Yohan Abeysinghe as an author. Titles, authors, links, venue badges, figure paths, intrinsic dimensions, and alt text remain in `_bibliography/papers.bib`. The template is `_layouts/bib.liquid`, and the light/dark colors and responsive layout are in `_sass/_site.scss`.
